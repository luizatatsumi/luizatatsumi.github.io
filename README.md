# Luiza Tatsumi — Portfólio

Site estático, responsivo e pronto para GitHub Pages. Não requer instalação, build nem dependências JavaScript.

## Publicar no GitHub Pages

1. Crie um repositório público no GitHub chamado `SEU-USUARIO.github.io` (substitua pelo seu nome de usuário) ou use outro nome.
2. Envie `index.html`, `style.css`, `script.js` e a pasta `assets/` para a raiz do repositório.
3. Acesse **Settings → Pages → Build and deployment → Deploy from a branch**, selecione `main` e `/ (root)` e salve.
4. Aguarde a publicação. O endereço será `https://SEU-USUARIO.github.io/` ou `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Personalizar

- **Foto:** substitua `assets/foto-preview.png` por uma imagem original de alta resolução com o mesmo nome. A foto atual foi recortada de uma captura do currículo e tem baixa resolução.
- **Projetos:** edite o array `projects` no começo de `script.js`. Os quatro projetos atuais são demonstrativos, não cases reais.
- **LinkedIn:** substitua `https://www.linkedin.com/` em `index.html` pela URL exata do seu perfil.
- **Contato:** o e-mail atual foi extraído do currículo; atualize caso deseje um endereço profissional.
- **Datas e cargos:** confirme os períodos de trabalho e cargos antes de divulgar.
- **Currículo PDF:** quando tiver o arquivo, coloque em `assets/curriculo.pdf` e adicione um link em `index.html`.

## Tecnologias
HTML, CSS e JavaScript sem frameworks. Fonte Manrope e DM Sans (Google Fonts, com fallback local).
